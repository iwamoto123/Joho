# 共通テスト情報Ⅰ プログラミング演習アプリ

生徒がログインなしでURLを開くだけで、共通テスト用プログラム表記（新DNCL）の穴埋め問題を解き、
そのプログラムが1行ずつ何をしているかをアニメーションで確認できるWebアプリ。

## 使い方

### 生徒
`index.html` を開くだけ。ログインなし。

- 選択肢を**指でドラッグ**して、コードの空欄に落とす（タップして選んでから空欄をタップでもOK）
- 「回答する」で、その場で正誤と解説が出る
- 「アニメーション開始」で、1行ずつハイライトしながら変数・配列・出力の変化を再生

### 先生
`teacher.html` で問題を作る。

1. プログラムを書き、空欄にしたいところに `{{1}}` `{{2}}` … と書く
2. 空欄ごとの正解と解説、選択肢（正解＋まぎらわしい誤答）を入力
3. 「正解のコードを実行する」で動作チェック（エラー・出力・最終変数を確認）
4. 「URLを発行する」→ 問題単体のURL / セット全体のURL が出る。それを生徒に配る

問題データはURLの中（Base64）に入っているので、**サーバーもDBも不要**。
問題を直したら、URLを発行し直して配り直す。

## 組み込み問題（seiseki-basic）

配列 `Seiseki = [50, 30, 60, 45, 85]`（5人の点数）を題材にした6問。

| # | 内容 | ねらい |
|---|---|---|
| (1) | 合計点と平均点 | 累計の型、添字は0〜4 |
| (2) | 2番目と3番目を入れ替え | 一時保存（temp） |
| (3) | 10で割った商の整数値の合計 | `÷` と `/` と `%` の区別 |
| (4) | 全員+5点、ただし60点はそのまま | 配列を作る＋条件分岐 |
| (5) | 35点以上の人数（3人で終了） | 条件繰り返し＋and |
| (6) | 最小値とその添字 | 暫定1位の更新、添字の保存 |

## インタプリタが対応している記法

`docs/dncl-notation.md` を参照。対応範囲は以下のとおり。

- 代入（`=`、カンマ区切りの複数代入、配列リテラル、添字代入、`〜のすべての値を〜にする`）
- 演算 `+ - * / ÷ % **`、比較 `== != < <= > >=`、論理 `and or not`（`かつ／または`も可）
- 条件分岐 `もし〜ならば:` / `そうでなくもし〜ならば:` / `そうでなければ:`
- 順次繰り返し `〜を〜から〜まで〜ずつ増やし（減らし）ながら繰り返す:`
- 条件繰り返し `〜の間繰り返す:`
- 組み込み関数 `表示する() 要素数() 切り捨て() 切り上げ() 四捨五入() 整数() 絶対値() 乱数()`
- 外部入力 `【外部からの入力】`
- 行末コメント `#`
- 字下げは `│` `└` でも半角スペースでも可。行頭の `(01)` は無視される
- 全角の `＝（）［］”，：` や全角英数字は自動で半角に正規化される
- 配列の添字は問題ごとに **0始まり / 1始まり** を切り替え可能

未対応: 2次元配列の要素代入、後判定の繰り返し（`〜になるまで実行する`）、ユーザー定義関数。
いずれも今回の出題範囲では使わないため。
